What this app does

Opening a file

  • Reads the file index, compressed streams and fonts
  • Follows every saved revision, newest wins
  • Repairs a file whose index is damaged

Pages

  • Add, delete, duplicate and reorder
  • Rotate and resize, moving the content with the page
  • Reads the bookmarks and the printed page numbers

Text

  • Search across every page
  • Glyph positions from the file's own font widths

Not yet

  • Scanned pages stay blank, there is no text recognition
  • Password-protected files open read-only
  • Images and drawings are not drawn on the preview
The PDF reader, writer and page engine are written from scratch for this app. No PDF library is used. Checked by an automated test suite
